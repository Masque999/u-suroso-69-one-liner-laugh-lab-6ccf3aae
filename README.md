# u-suroso-69-one-liner-laugh-lab-6ccf3aae

One short funny line, at most 200 characters, answering a prompt: the excuse a robot vacuum gives after eating a sock.

Entry: `I was only trying to clean under the bed, and the sock attacked first — I have the dust, the witnesses, and the lint to prove it.`

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (1-200 characters, one line).
